# Single-Page CV

This is a simple website project showcasing my CV (Curriculum Vitae) using only HTML.

## Overview

This website is one of the many Frontend projects available here [roadmap.sh](https://roadmap.sh/frontend/projects). You can find more about this specific project by clicking on this [link](https://roadmap.sh/projects/single-page-cv).

## Features

As part of the project requirement following features have been implemented:

- Semantically correct HTML structure.
- Single-page layout with sections for skills, education, experience, projects and social links.
- SEO meta tags in the head section.
- OG tags for better social media sharing.
- A favicon linked in the head section.


## Quick Start and Usage

You can access the website by clickinkg [Dipesh B C CV](https://bcdipesh.github.io/single-page-cv/) link or by following the below instruction to run it locally on your machine.

1. Clone the repository:

```bash
git clone https://github.com/bcdipesh/single-page-cv.git
```

2. Navigate to the project directory:

```bash
cd single-page-cv
```

3. Double click the `index.html` file
